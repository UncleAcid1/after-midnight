Midnight Mansion HD (MMHD) Custom Mansions


The following information, along with images, can be found in the


  Midnight Mansion HD FAQ 

  http://www.actionsoft.com/games/midnightmansionhd/faq.php


  Custom mansions in MMHD use the zip file format, So the [Mansion Name].zip file contained in this distribution can be placed placed unopened in the custom mansion directory.  This directory can be found in the same directory containing the game. If you do not see this directory, then it may not have been created yet. The game will create the directory when you select "Open Mansion" from the main screen the first time.


 MMHD can play the custom mansion from the zip file directly, or opened up. Note that if you choose to open the zip file, you will first need to create a folder for that mansion, and open the zip file in that folder. When you choose "Open Mansion" from the main screen, you will be able to select the zip file or the expanded directory. Note that for some older machines, or for some very large mansions, there may be a short lag between rooms when using the zip file.
